O que é o Shambleta

Shambleta é um MMORPG 2D (Godot 4) que funciona no navegador. Você loga, escolhe uma zona de farm e o personagem luta automaticamente — o "idle-first" que define a experiência.

O jogo conecta via WebSocket ao servidor autoritativo (`wss://`), com economia real (gems, VIP, baús provably-fair), rebirth e guildas. A versão web é o pivô: primeira carga medida em ~32,4 MB (gzip), com meta de <25 MB após otimização de texturas.

Dados técnicos (beta)

  • Engine: Godot 4.7.2
  • Servidor: Godot headless + Python companion
  • Web: WASM + WebSocket (COOP/COEP obrigatório)
  • Build: `index.pck` 36 MB raw (20,7 MB gzip)
  • VPS recomendada: 2 vCPU / 12 GB RAM (Ampere A1)

Como funciona

O cliente web é exportado pelo Godot (`--export-release "Web"`). O nginx serve os arquivos com gzip nível 9 e os headers `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy` necessários para o `SharedArrayBuffer` do WASM.

A landing que você está vendo agora é independente: pode ser um site estático, um SPA ou uma página customizada antes de redirecionar para `index.html`. O jogo roda na mesma janela, sem iframes obrigatórios.

Guia rápido

Como começar, o que fazer e como evoluir — sem complicação.

1. Entre

Não precisa instalar nada. Abra o jogo no navegador, crie uma conta (com consentimento LGPD afirmativo) e faça login. O jogo inicia diretamente no modo idle.

2. Escolha a zona

Use `/farm` ou o painel para trocar de zona. Zonas mais profundas precisam de um score de poder maior (F3). A zona 1 é aberta para todos.

3. Colha enquanto está offline

Quando volta a logar, o `OfflineSettle` liquida os ganhos acumulados (XP, ouro, drops). Isso é o coração do idle.

4. Progresso e temporada

Baús (`/chests`), boss ladder, vip e o passe de temporada (S1) têm regras congeladas. As 4 corridas da temporada (`Power`, `Spend`, `Boss Kills`, `Guild Points`) já têm snapshot e premiação automática implementados.
